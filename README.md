# 🌷 Taskly - Personal Academic Planner

Taskly is a Progressive Web Application (PWA) designed specifically for students to organize tasks, manage deadlines, and track their academic journey efficiently. Built with React and Vite, Taskly provides a seamless, app-like experience that works even when you're offline!

## ✨ Key Features
- **📊 Interactive Dashboard:** Get a quick overview of your academic progress, total tasks, and upcoming deadlines.
- **📝 Task Management:** Categorize your assignments into To Do, In Progress, and Completed.
- **📱 PWA Support:** Installable on desktop and mobile devices. Fully functional offline!
- **🧑‍🎓 Student Profile:** Keep track of your academic identity and details.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite
- **Styling:** CSS
- **Icons:** Lucide React
- **PWA:** vite-plugin-pwa (Service Workers & Manifest)

## 🚀 How to Run Locally
1. Clone the repository: `git clone https://github.com/NanditaDindaI/taskly.git`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. For testing the PWA build: `npm run build` then `npm run preview`
